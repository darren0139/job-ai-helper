### Concrete blockers

1. **Nullable summary and presentation:** a genuine v1.20 null alignment becomes zero in `summarize_stable_match`; REVIEW rows are counted as unmatched NONE. Job Finder displays that number as `/100`. The application details renderer instead raises on `int(None)`, with additional `None%`/band formatting risks. Neither is an acceptable review UX. Phase 8 contribution reconstruction must not fabricate zero-valued review credit if a future published version identity makes that path eligible.
2. **Source projection scope:** structured original project/experience paths and raw text are both passed by the actual Job Match adapter. Raw text is a deduplicated flattening, without per-line project ownership. The v1.20 ledger deliberately retains raw originals, so a repeated denied claim can lose its known project scope in the raw projection. This is a separate adapter problem from a selected-positive conflict in the original Stage 2I fixtures. Original library item IDs are retained in `evidence_snapshot`, but are not carried on projected project/experience records or native evidence source paths. A preview needs verified mapping of projected occurrences to canonical item/field/line origins, not an invented safe source or a new ranker.
3. **Preview identity and refresh isolation:** normal application currentness has a different authority/version namespace. A preview may be treated as stale and rebuilt through the OFF scorer. A preview controller must retain its own receipt and must never let normal refresh, saved reuse, ranking or initial-binding code substitute another analysis.
4. **No nonpersisting application controller:** `analyze_job_match` couples cache lookup, model-backed extraction, summary and save. Its injectable builder is a useful test seam, not a supported release switch. Public writers correctly reject gated results. An explicitly separate comparison route must bypass saved-score consumers and all writes.
5. **Release regression evidence is incomplete outside the coordinated contract:** full project checks were attempted in containment, but a blueprint smoke attempts artifact materialization outside its disposable root. It was blocked. A green isolated full CI run remains necessary before release; this audit does not classify a containment failure as a scoring defect or claim the full suite passed.
